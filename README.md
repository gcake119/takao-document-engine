# takao-document-engine

This repository owns the document-engine component of Takao City.

Coordination and product contracts: https://github.com/gcake119/takao-city

Application implementation and application CI have not been initialized.
The initial CI baseline verifies repository ownership, documentation and runner controls only.
It is not evidence of a working application, extraction quality, deployment, or human acceptance.
Do not commit real municipal documents, databases, credentials, or private data.

## CI baseline

Repository ownership/privacy/documentation and Mint runner controls are verified by an infrastructure-only baseline. Application implementation and acceptance remain separate. See [CI scope](docs/ci-baseline.md).
